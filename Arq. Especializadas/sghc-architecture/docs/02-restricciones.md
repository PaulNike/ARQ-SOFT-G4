# 2. Restricciones

## 2.1 Restricciones legales y normativas

- Cumplimiento de **Ley de Protección de Datos Personales**.  
- Retención mínima de **10 años** de información clínica:contentReference[oaicite:4]{index=4}.  
- Trazabilidad completa de accesos y modificaciones.  
- Cifrado en tránsito (TLS 1.3) y en reposo (AES-256).

## 2.2 Restricciones técnicas

- Conectividad mínima 50 Mbps entre sedes:contentReference[oaicite:5]{index=5}.  
- Estándares clínicos: **CIE-10**, **Vademécum local**.  
- Uso de estándares de interoperabilidad **HL7/FHIR**.  
- Arquitectura con soporte para escalado y failover (Kubernetes gestionado).

## 2.3 Alcance fuera del MVP

- Telemedicina en tiempo real.  
- Analítica avanzada o investigación clínica.  
- IA para codificación automatizada (previsto para Fase 3).
