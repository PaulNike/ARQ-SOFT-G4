# 3. Contexto y Alcance

## 3.1 Alcance del MVP

- Gestión de pacientes (alta, actualización, búsqueda, unificación).  
- Gestión de citas (agenda, check-in).  
- Atenciones médicas (motivo, evolución, diagnóstico CIE-10).  
- Recetas electrónicas y órdenes de laboratorio.  
- Gestión documental (PDF, imágenes).  
- Portal paciente (web/móvil).  
- Gestión de usuarios, roles y auditoría:contentReference[oaicite:6]{index=6}:contentReference[oaicite:7]{index=7}.

## 3.2 Fuera de alcance

- Telemedicina en tiempo real.  
- Analítica poblacional.  
- IA de soporte clínico.

## 3.3 Actores principales

| Actor | Rol / Interacción |
|--------|------------------|
| Paciente | Accede a portal, citas, resultados. |
| Médico / Enfermería | Registra evolución y diagnósticos. |
| Recepción | Agenda citas, realiza check-in. |
| Farmacia | Procesa recetas electrónicas. |
| Laboratorios externos | Envían resultados digitales. |
| Auditoría / Cumplimiento | Supervisa trazabilidad y acceso. |
| Aseguradoras | Autorizan servicios clínicos. |
