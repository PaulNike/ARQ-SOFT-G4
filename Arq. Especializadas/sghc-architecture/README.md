#  SGHC — Sistema de Gestión de Historias Clínicas  
### Documentación Arquitectónica (arc42 + Markdown + Git)

---

##  Descripción general

Este repositorio contiene la **documentación de arquitectura** del sistema **SGHC (Sistema de Gestión de Historias Clínicas)**, desarrollado para la red de clínicas *Salud Integral*.

El proyecto aplica el framework **arc42**, versionado en **Markdown**, con soporte para **Git**, **PlantUML**, y **Structurizr DSL**, permitiendo mantener una documentación **"as code"**, trazable, auditable y fácil de evolucionar.

---

##  Propósito

El objetivo principal de este repositorio es centralizar la documentación técnica del SGHC, cubriendo todos los aspectos arquitectónicos del sistema desde la visión de negocio hasta las decisiones técnicas, siguiendo el estándar **arc42**.

La documentación busca:

- Alinear los **objetivos de negocio** con las **decisiones de arquitectura**.
- Asegurar **transparencia, trazabilidad y mantenibilidad**.
- Servir como fuente de verdad para **desarrolladores, QA, DevOps y auditores**.
- Facilitar la comunicación técnica entre stakeholders clínicos y tecnológicos.
